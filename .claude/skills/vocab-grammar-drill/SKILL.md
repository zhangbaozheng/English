# 词汇语法练习(vocab-grammar-drill)

这是英语入门班学习资料的固定学习流程,已经在「名词」专题上跑通一次,以后学动词、形容词、副词等,都复用同一套流程,只换输入材料和子目录名。

## 何时使用

用户提供某个词性的语法讲义(截图或文字)+ 提到要"练习""生成练习大纲""按 skill 走"时触发。

## 输入

1. **语法讲义**:该词性的语法点讲解,来源可以是拍照的教材截图,也可以是已有的 md 文件。先通读,提炼出模块划分(一般是"定义 → 分类 → 变形规则 → 特殊/不规则情况 → 在句中的作用 → 其他专项如所有格/时态/比较级"这样的顺序,具体模块以实际讲义为准,不要生搬硬套名词的七模块)。
2. **专用词表**:项目根目录下的「英语入门班造句专用{动词/名词/形容词}表（新）PDF.pdf」。这些词表按语义分类(如名词表分"表示人的名词""表示事物的名词"),并带有该词性特有的变形信息列(名词表有"变复数规则"列;动词表、形容词表按实际内容确定有没有类似的规则列,没有就靠自己按语法点归类)。
3. **全局词汇库(出题时必查)**:根目录下的「数词表格.doc」(基数词/序数词)、「英语量词.docx」(量词用法)、以及已产出的「动词/」「名词/」「形容词/」专题词表(各自的专用词表 PDF)。这几份材料合起来就是学生目前**全部学过的词汇范围**。

## 出题用词的硬性约束(所有练习共用)

**句子里出现的每一个实词(名词、动词、形容词、数词、量词),都必须能在上面第3点的全局词汇库里查到,禁止凭空使用词表之外的单词。** 这一条比"出题原则1"(例词来自当前单元区间)范围更广、优先级更高,原因是:学生只学过这几张表里的词,表外的词他没见过,写进句子里等于超纲。

- 当前专题的目标词性(比如正在学形容词)从**当前单元的编号区间**里选(仍遵守出题原则1)。
- 句子里搭配用的**其他词性**(比如形容词题里搭配的名词、动词)要从**已经产出的对应词性词表**里选:
  - 名词 → 查「名词/词表单元划分.md」对应的「造句专用名词表 PDF」(如果名词专题还没做,退化为只用讲义/教材原文里出现过的名词,并在题目旁注明)。
  - 动词 → 查「动词/词表单元划分.md」对应的「造句专用动词表 PDF」(同上,没有就只用讲义原文出现过的动词)。
  - 数词(如"三本书"的"三") → 查根目录「数词表格.doc」。
  - 量词(如"一杯茶"的"杯") → 查根目录「英语量词.docx」。
- `.doc`/`.docx`/`.pdf` 是二进制文件,不能直接用文本工具搜索,出题前先用对应技能(docx/pdf 相关 skill,或已经读取过并记在该词性讲义里的内容)确认词是否存在,不要凭记忆/常识猜测这些表里有没有这个词。
- 如果某个句子确实需要一个不在任何表里的词(比如为了讲清楚某条语法点,教材例句本身就用了表外词),优先**直接照抄讲义原句的词**(参照出题原则6"仅限讲义原例"的处理方式),而不是自己另造一个表外新词;如果连讲义原句都没有覆盖,先跟用户确认是否要临时放宽,而不是默认放行。
- 批改时如果发现自己出的题用了表外词,要在批改说明里坦诚指出并改正,不能默认"学生看得懂就行"。

## 产出物(从「动词」专题起是五件套,此前是四件套)

参照仓库里「句子成分与基本句型/」目录的组织方式,在词性对应的子目录下(如 `名词/`、`动词/`、`形容词/`)生成:

- `知识点讲义.md` — 把散落的讲义截图/文字浓缩整理成条理化的 markdown 讲义,按模块编号(一、二、三……),一次性写完整,不分轮。
- `词表单元划分.md` — 把专用词表(约400词)按**每50个词一个单元**切分,直接引用词表自带的编号区间(如"人的名词1~50""事物的名词229~278"),不重新抄词,用户自己对照 PDF 查词。**文件末尾维护一个"已用词记录"区**(见下面出题原则8),每出完一次测验(不管是 `单元测试.md` 还是 `基础知识测试.md`)就把这次实际用到的名词/形容词/数词/量词追加进去,按词性分行列出,方便新会话接手时一眼看出哪些词已经用滥了、哪些还没碰过。
- `单元测试.md` — **只放句子翻译测验**,标题固定写"第N单元",N 跟着 `词表单元划分.md` 里的词表单元顺延累加。中文句子→翻译成英文,句子里同时揉合"之前学过的句型"(主谓/主系表/主谓宾/双宾语/宾补/定语等)和"当前词性的语法点",不出现脱离句子的抽象判断题,语法点必须体现在一句完整的、要翻译的中文句子里。
- `基础知识测试.md`(**新增,从「动词」专题开始产出;此前的名词/代词/形容词专题没有这个文件,不需要回头补**)——**独立的文件**,不跟 `单元测试.md` 的词表单元1:1绑定,标题固定写"第N次",N 是这个文件自己的独立计数。可以在 `单元测试.md` 还没出完对应单元的时候先出,也可以攒到某几个单元结束后再出,由知识点讲义的模块覆盖进度决定节奏,而不是被词表单元的进度牵着走。直接考讲义里的语法概念本身,不必都包在完整句子里,题型可以是:写出某个词的过去式/过去分词/现在分词/第三人称单数等变形、判断词的类型或用法归类(如不及物/及物、系动词/助动词/情态动词/实义动词)、按规则分类或应用变形规则、给系动词/助动词的例句挑出对应功能并说明理由、简答"为什么不能这样用"等。这个文件是为了做到"全方面考基础知识",不只靠句子翻译去覆盖讲义的每个模块——有些概念(比如"助动词有没有意思""系动词只能跟什么作表语")很难自然揉进一句翻译题里,直接考更高效。
- `错题追踪.md` — 实时更新的错题/掌握度追踪表(结构见下),这是这套流程的核心产出,保证"吃透逻辑"而不是"做完就扔"。**`单元测试.md` 和 `基础知识测试.md` 两个文件的错题统一写进同一份表**,"首次出现单元"这一列按实际来源填"第N单元"或"基础知识测试第N次"。

两个测验文件**各自独立出题、独立批改、独立编号**,互不阻塞:`单元测试.md` 卡在某单元没批改,不影响 `基础知识测试.md` 出下一次;反之亦然。每次批改后都在对应文件里追加"本次考点分布"表逐题标注该题具体考的是哪条逻辑(引用知识点讲义模块编号),不需要在出题时就剧透。

## 出题原则

0. **(前置检查)先满足上面"出题用词的硬性约束",再考虑覆盖面和句子设计**——句子里所有实词都要能在数词表格/量词表/动词表/名词表/形容词表(或讲义原句)里查到,这一条优先于下面所有原则。
1. 每道翻译题的例词**必须来自专用词表当前单元的编号区间**,不要用区间外的词凑数。
2. 一道句子尽量同时覆盖 1~2 个语法点(比如"这是尼克的妻子" 同时考's所有格 + 可数名词单数需要限定词),但不要堆砌到看不出考点。
3. 讲义里特别强调的"反直觉例外"(如名词部分 sky 可数复数 skies、water 不可数)要在覆盖到相应单元时安排进句子里。
4. 难度控制:句子要自然、贴近教材已学的句型和词汇,不引入没学过的复杂结构;"不要太难"优先于"覆盖面广"。
5. 每单元测验量:按该单元词数灵活定,一般 12~20 句能覆盖大部分词即可,不要求每个词都单独成句。
6. **讲义里自带固定例词/例句的语法点**(比如名词的"of + 无生命名词"所有格、不可数名词量词表达,讲义只给了 house/coat/carrot/water/oil/school/book/exam/newspaper、cup/bottle/bucket/tin/kilogram/basket/box 配 tea/coffee/milk/oil/meat/apples/books 这一小套),出题时**只用讲义里出现过的原词**,不要另外从专用词表挑词自由搭配组合——这类语法点的重点是记住固定搭配和例外,不是泛化练习。换到动词/形容词时,遇到讲义里同样"给了一小套固定例词"的语法点,也按这条处理。
7. **`基础知识测试.md` 的出题范围**:优先覆盖讲义里"容易脱离句子考、但不考就容易被绕过"的概念点,比如变形规则本身(不规则变化五类怎么分、规则变化的双写辅音/改y为i等细则)、词的功能分类(某个词在具体例句里到底是实义动词/系动词/助动词/情态动词,为什么)、"没有意思但不能省略""不能单独使用"这类特点。基础知识测试里出现的例词,同样要遵守"出题用词的硬性约束"(不能用表外词),但如果是纯语法概念题(比如"实义动词分哪几种")可以不涉及具体词,不受此约束。每次基础知识测试量不用太大,10~16题能覆盖到目前讲过的几个模块即可,不必每次都覆盖全部模块。
8. **广度优先,主动避开高频重复词(硬性要求,不是建议)**:出题前先看 `词表单元划分.md` 末尾的"已用词记录",把里面已经反复出现过的词(比如 teacher/book/cup/city/cake 这类"熟词")排除掉,优先从名词表(396个)、形容词表(116个)、数词表格、量词表、动词表(96个)里挑**还没用过或用得少**的词。不要因为好翻译就每次都用同一小撮词,几百个词的词表如果反复用不到20个,就失去了"覆盖全表"的意义。每次测验的目标是尽量往词表深处走(比如名词表里"表示事物的名词"有324个,不能一直只用前50个里的那几个常见词)。出完题后,把这次真正用到的词追加进"已用词记录",供下次出题参考。
9. **句型多样性,覆盖已学的所有句型至少一遍**:参照「句子成分与基本句型/知识点讲义.md」里的五个基本句型(主谓、主系表、主谓宾、主谓双宾、主谓宾补)以及本词性讲义里教到的其他结构(疑问句、否定句、现在完成时、被动语态提及、情态动词句、系动词句等),不要每次测验都套用同一个句子模板(比如总是"某人每天做某事吗?")。同一批测验里尽量让句型有变化,几次测验累积起来要能覆盖到目前教过的全部句型结构。

## 单元测验 + 批改 + 错题追踪流程

**`单元测试.md`(句子翻译)**:
1. 从 `词表单元划分.md` 取下一个待测单元的编号区间,出一份句子翻译测验,写入 `单元测试.md`(标题按"第N单元"顺延累加,不新开文件)。
2. 每道题下方留空行,等用户把英文翻译写在下面。
3. 用户作答后逐题批改,追加"本单元考点分布"表,并把答错的题写入 `错题追踪.md`(格式见下)。
4. 批改完成后,把这次测验里实际用到的名词/形容词/数词/量词追加进 `词表单元划分.md` 的"已用词记录"。
5. 出下一次测验时,先看"已用词记录"避开高频词(出题原则8),再从 `错题追踪.md` 里挑出属于这个文件的"待复习"/"复习中"逻辑点混进去。

**`基础知识测试.md`(从「动词」专题起新增)**:
1. 不依赖词表单元划分的进度,按知识点讲义已经覆盖的模块自行安排,出一份概念题测验,写入 `基础知识测试.md`(标题按"第N次"顺延累加,自己独立计数,不新开文件)。
2. 每道题下方留空行,等用户作答。
3. 用户作答后逐题批改,追加"本次考点分布"表,并把答错的题写入同一份 `错题追踪.md`;如果题目里用到了具体例词,同样追加进 `词表单元划分.md` 的"已用词记录"。
4. 出下一次测验时,同样先从 `错题追踪.md` 里挑出"待复习"/"复习中"的逻辑点混进去——不区分是 `单元测试.md` 还是 `基础知识测试.md` 考出来的错题,只要没到"已掌握"就要混入两个文件各自的下一次测验里。

**两个测验文件共用的错题追踪规则**:
- 答错的题按下面结构写入(或更新)`错题追踪.md`:

     ```
     | 语法逻辑点 | 涉及单词/句子 | 错误次数 | 连续答对次数 | 状态 |
     |---|---|---|---|---|
     | 模块四·不规则复数 man→men | 那些男人是警察。 | 1 | 0 | 待复习 |
     ```

- 状态只有三种:`待复习`(还没考过或刚考错)、`复习中`(答对过至少1次但未满2次连续正确)、`已掌握`(连续答对2次,不再主动重考,但仍保留记录)。
- 全部 `单元测试.md` 单元过完一轮后,检查 `错题追踪.md` 里是否还有非"已掌握"的条目,如果有,继续专门为这些条目出针对性小测验(可以在 `单元测试.md` 里出"专项突破",也可以用 `基础知识测试.md` 单独出一次),直到清空或用户明确说不用再练。
- 视需要再补一份 `造句练习.md`(开放式造句,不强制批改逻辑点),参考「句子成分与基本句型/造句练习.md」的组织方式。

## 断点续练(新终端/新会话怎么接手)

每次新开的 Claude 会话都没有之前的对话记忆,**所有进度必须能从文件里读出来**,不需要用户重新解释"我们做到哪了"。被要求"继续 XX 的练习"或直接调用这个 skill 时,按下面顺序确定现状:

1. 找到用户指的词性子目录(没说清楚就问,或者看仓库里哪个 `<词性>/` 目录下有 `词表单元划分.md`)。
2. **`单元测试.md`**:打开 `<词性>/词表单元划分.md`,看单元表最后几行的"状态"列:
   - `待测` → 还没出这个单元的题,直接出题(按下面的错题追踪流程混入待复习项)。
   - `测验已发,等待作答` → 打开 `<词性>/单元测试.md` 看对应单元的题目下面有没有被填上答案:有答案但该单元后面还没有对应的"批改结果"小节 → 先批改,不要重新出题;完全没答案 → 提醒用户去作答。
   - `已测,X/Y对……` → 这个单元已经批改完了,看有没有留下"专项突破""补充练习"之类的未完成小节,没有就直接进入下一个待测单元。
3. **`基础知识测试.md`(仅动词及之后的专题会有这个文件)**:如果存在,打开它找最后一个"第N次"标题,看它后面有没有作答、有没有对应的"批改结果"小节,判断逻辑跟 `单元测试.md` 一样(没答案→提醒作答;有答案没批改→先批改;已批改→可以出下一次)。这个文件和 `单元测试.md` 的进度互相独立,不要因为一个卡住就连带认为另一个也没法继续。
4. 打开 `<词性>/错题追踪.md`,看有没有"待复习"/"复习中"的行——出下一份题目时(不管是给哪个文件出)都必须把它们混进去,规则参照上面"单元测验 + 批改 + 错题追踪流程",不要凭感觉重新设计一套。
5. 打开 `<词性>/知识点讲义.md` 确认模块划分,以及有没有标注"仅限讲义原例"的语法点(如 of+无生命名词、不可数名词量词),出题时遵守出题原则第6条。
6. 确定好现状后直接执行下一步(出题 / 批改 / 专项突破),除非文件状态和用户的描述对不上,才需要先跟用户确认。

## 复用到下一个词性时

1. 新建对应子目录(如 `动词/`),重复"讲义整理 → 词表单元划分 → 单元测验 → 批改 → 错题追踪 → 混入复习"这一整套流程(产出物见上面"产出物"一节)。
2. 讲义模块划分要从新讲义本身提炼,不要照抄名词的七模块结构。
3. 词表换成对应词性的专用词表 PDF,单元切分方式(每50词一单元)保持不变。
4. 出题原则(所有实词必须来自数词表格/量词表/动词表/名词表/形容词表或讲义原句、当前专题目标词必须来自当前单元区间、讲义固定例词的语法点只用讲义原词、错题实时混入后续单元直到连续答对2次)保持不变;`单元测试.md` + `基础知识测试.md` 的双文件结构(从动词专题开始生效)也保持不变。
5. 完成后,在根目录 `CLAUDE.md` 里补充新子目录的一行说明,保持文档同步。
